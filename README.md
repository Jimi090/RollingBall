# Rolling Ball

Rolling Ball is a 3D platformer where your goal is to collect crystals as fast as you can!

![PromoImage1](/PromotionImages/Image1.png)

### Features

- Move the ball using WASD, arrow keys and space
- 3 levels with increasing difficulty
- Tutorial for new players
- Intuitive menu
- Rotating crystals

### Demo

### Controls

- WASD or arrow keys -> movement
- Space -> jump
