# Rolling Ball

Rolling Ball is a 3D platformer where your goal is to collect crystals as fast as you can!

![PromoImage1](/PromotionImages/Image1.png)

### Features

- Move the ball using WASD, arrow keys and space
- 3 levels with increasing difficulty
- Tutorial for new players
- Intuitive menu
- Rotating crystals

### Controls

- WASD or arrow keys -> movement
- Space -> jump

### Opening the Project

1. Clone or download this repository.
2. Open Unity Hub.
3. Select Add project from disk.
4. Select the UnityProject folder.
5. Open the project using Unity 6.
6. Open the MainMenu scene from the Assets/Scenes folder.
7. Press Play to run the game in the Unity Editor.
